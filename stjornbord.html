What this demo is

A working request loop with no server behind it: requests live in this browser only, so nothing here is real guest data and nothing leaves the machine. In a live version the requests would arrive by email as well, and this list would be the record that decides what is agreed.

No card is ever entered, by design. The guest asks, you confirm, money changes hands the way it does now. That means no payment plumbing, no chargebacks, and no monthly card fees.
